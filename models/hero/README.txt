Drop the hero's rigged model here:

  models/hero/hero.fbx          the character from Mixamo (FBX Binary, T-pose, With Skin)
  models/hero/anims/idle.fbx     each animation from Mixamo (FBX Binary, Without Skin, In Place)
  models/hero/anims/walk.fbx
  models/hero/anims/run.fbx
  ...

File names become animation names. Useful ones:
  idle, walk, run, walk_back, jump, fall, swim, tread, hit, death, getting_up, aim_idle

Check it with: godot_console --path . res://tools/rig_preview.tscn
