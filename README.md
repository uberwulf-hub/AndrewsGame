# Finding Home: A Whispering Woods Adventure

A third-person adventure prototype made with Godot 4.7.

## Build
Install the Godot 4.7.2 export templates, then:
```
godot_console --headless --path . --export-release "Windows Desktop" build/AndrewsGame.exe
```
`export_presets.cfg` leaves the editor tools and source meshes out of the build.

## Store
`saucestore.json` and `store/icon.png` list the game in SauceStore. Each release attaches `FindingHome-windows.zip`.

See CREDITS.md for third-party assets.
